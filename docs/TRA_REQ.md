# [TRA] 요구사항정의서

> 화면 2개 롤업(소분류 TRA, 대분류 TR - 계좌이체 및 자동이체).

## TRA-001 계좌간 이체

> 원본: `fineract-backoffice-ui/src/app/features/transfers/account-transfers-list.component.ts`

### 요구사항 목록
| 요구사항ID | 유저스토리 | 주요 기능 | 성공 기준 |
| :--- | :--- | :--- | :--- |
| `FR-TRA-001` | US1 | 당행 계좌간 즉시 이체 실행 | `SC-001` |
| `FR-TRA-002` | US1 | 계좌이체 이력 조회 및 영수증 출력 | `SC-002` |

### `FR-TRA-001` 당행 계좌간 즉시 이체 실행
- **유저 스토리 (US1)**: 담당 사용자는 계좌간 이체 화면에서 당행 계좌간 즉시 이체 실행을(를) 수행하여 업무를 처리할 수 있다.
- **기능 명세**:
  - 출금 계좌 및 입금 계좌 선택, 이체 금액 입력 후 실시간 잔액 차감/가산 및 이체 원장 생성
- **성공 기준 (`SC-001`)**:
  - 정상 요청 시 데이터가 정확히 처리/조회되고 화면에 오류 없이 반영된다.

### `FR-TRA-002` 계좌이체 이력 조회 및 영수증 출력
- **유저 스토리 (US1)**: 담당 사용자는 계좌간 이체 화면에서 계좌이체 이력 조회 및 영수증 출력을(를) 수행하여 업무를 처리할 수 있다.
- **기능 명세**:
  - 기간별/계좌별 이체 거래 내역 조회 및 거래 확인증 출력
- **성공 기준 (`SC-002`)**:
  - 정상 요청 시 데이터가 정확히 처리/조회되고 화면에 오류 없이 반영된다.

## TRA-002 자동이체(SI) 관리

> 원본: `fineract-backoffice-ui/src/app/features/transfers/standing-instructions-list.component.ts`

### 요구사항 목록
| 요구사항ID | 유저스토리 | 주요 기능 | 성공 기준 |
| :--- | :--- | :--- | :--- |
| `FR-TRA-003` | US2 | 정기 자동이체(Standing Instruction) 등록 및 조건 설정 | `SC-003` |
| `FR-TRA-004` | US2 | 자동이체 배치 실행 이력 모니터링 | `SC-004` |

### `FR-TRA-003` 정기 자동이체(Standing Instruction) 등록 및 조건 설정
- **유저 스토리 (US2)**: 담당 사용자는 자동이체(SI) 관리 화면에서 정기 자동이체(Standing Instruction) 등록 및 조건 설정을(를) 수행하여 업무를 처리할 수 있다.
- **기능 명세**:
  - 이체 주기(일/월), 이체 실행일, 약정금액, 유효기간 지정 후 자동이체 등록
- **성공 기준 (`SC-003`)**:
  - 정상 요청 시 데이터가 정확히 처리/조회되고 화면에 오류 없이 반영된다.

### `FR-TRA-004` 자동이체 배치 실행 이력 모니터링
- **유저 스토리 (US2)**: 담당 사용자는 자동이체(SI) 관리 화면에서 자동이체 배치 실행 이력 모니터링을(를) 수행하여 업무를 처리할 수 있다.
- **기능 명세**:
  - 스케줄러에 의한 자동이체 실행 결과(성공/잔액부족 실패) 이력 조회
- **성공 기준 (`SC-004`)**:
  - 정상 요청 시 데이터가 정확히 처리/조회되고 화면에 오류 없이 반영된다.
